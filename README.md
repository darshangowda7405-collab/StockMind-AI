# 📈 StockMind AI

## Explainable AI Powered Stock Analysis & Prediction Platform

StockMind AI is a full-stack fintech application that combines machine learning, technical analysis, and explainable AI to help users analyze stock market trends.

## Features

- AI Stock Prediction
- Bullish / Bearish Forecast
- Confidence Score
- Technical Indicators
- Explainable AI
- Historical Backtesting
- Portfolio Tracking
- Watchlist
- News Sentiment Analysis
- Interactive Charts
